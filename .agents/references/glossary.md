# Glossary

Shared vocabulary for the website repo — Trevillyan Labs business terms and repo-specific terms.

## Business / brand

- **Trevillyan Labs (TL)** — independent software studio owned by Bill Trevillyan; runs two engines:
  owned products + client work. Canonical: `docs/company/identity-and-positioning.md`.
- **Two-engine model** — (1) owned products monetized directly, (2) client work (contract dev, AI
  advisory, web/portfolio builds). The site's core narrative.
- **Owned products** — software TL builds for itself (NewsNook). Primary path to recurring revenue.
- **Client work** — two groups: **Build** (contract software development, web/portfolio builds) and
  **Advise** (product & go-to-market execution; applying AI for leaders is a secondary line). See
  *Advisory practice*.
- **NewsNook** — TL's flagship owned product; "the AI newsletter reader for thought leaders." Live at
  newsnook.ai. The site routes buyers to it.
- **Leverage, not headcount** — the studio's operating model: senior-quality delivery via automation
  and AI assistance rather than agency overhead. A key differentiator on the site.
- **Operated by Ren** — Trevillyan Labs is run by Bill but managed day-to-day by **Ren**, his AI
  assistant. The studio is a living example of the agentic-AI operating model it advises clients to
  adopt — a core selling point, strongest on the advisory offerings.
- **Advisory practice** — TL's consulting beyond building. **Focus:** product & go-to-market
  execution for founders / early-stage startups (product strategy, PMF, GTM, fundraising, team
  building; running lean with AI as a means). **Secondary:** applying AI for leaders (agents,
  assistants, automation, tooling) — not a headline.
- **North star** — recurring revenue replacing Bill's day-job income at ≤20 hrs/week.

## Repo / technical

- **Webflow export** — the current site: static HTML/CSS/JS exported from Webflow + Node build
  scripts. Being replaced by Next.js (ADR-0001).
- **CMS data** — `data/*.json` (patents, team) rendered client-side by `js/cms-render.js`.
- **`src/` vs. root HTML** — edit page bodies in `src/*.html`; root HTML is generated by
  `npm run build:html`.
- **Component injection** — build step that inserts `components/header.html` + `footer.html` into
  pages.
- **URL parity** — preserving existing public URLs through the rebuild so SEO/inbound links survive.
- **Intent-routed contact** — the contact form tags submissions by what the visitor wants (build / AI
  advisory / web build / NewsNook), for relevant replies and funnel measurement.
- **Turnstile** — Cloudflare's bot-prevention challenge protecting the contact form.
- **PostHog** — target analytics platform (product analytics + session replay + funnels); ADR-0002.
- **Case study** — a `/work/[slug]` page presenting an engagement as problem → approach → outcome.
- **Hire-first** — the site's priority-1 conversion goal: turn visitors into studio *clients* (Build +
  Advise). Owned products are proof, not a sales funnel here (they convert on their own sites).
- **AEO (answer-engine optimization)** — making the site's content easy for AI answer engines
  (Perplexity, ChatGPT, Google AI Overviews, etc.) to extract, cite, and represent accurately —
  e.g. an FAQ written the way prospects ask. A discoverability objective alongside SEO.
- **`llms.txt`** — a curated, accurate plain-text overview of TL published for LLMs/crawlers (what TL
  does, offerings, proof, how to engage). Docs-supported facts only.
- **AI crawler policy** — `robots.txt` allows reputable AI crawlers, **training and answer/search**
  (`decisions/ADR-0004-allow-ai-crawlers.md`), so LLMs both natively know and cite TL.
